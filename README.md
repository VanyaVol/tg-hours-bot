# 🤖 Telegram Bot: Бот обліку годин

Простий та швидкий Telegram-бот на **TypeScript** та **grammY** для фіксації відпрацьованих годин працівниками агенцій праці в Польщі.

---

## 🚀 Швидкий старт (Локальний запуск)


### 1. Клонування проєкту та встановлення залежностей
Перейдіть у папку з проєктом та встановіть усі необхідні npm-пакети:
```bash
npm install
```
### 2. Запуск проєкту
```bash
npm run dev
```
